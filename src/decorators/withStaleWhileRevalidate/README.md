# 💾 Декоратор `withStaleWhileRevalidate`

Эта утилита перехватывает вызовы `fetcher`, сохраняя последнее успешное состояние данных для возврата в случае сетевых сбоев или отмены запросов.

## Кейсы применения
* **Интерактивные карты и скролл**: предотвращает моргание и очистку интерфейса во время загрузки новых данных.
* **Сетевые сбои**: защищает от пустых экранов при кратковременной потере связи, отдавая последний валидный кэш.
* **Быстрые фильтры**: удерживает предыдущее состояние элементов управления до получения актуального ответа.
