## Главные особенности реализации под Яндекс Карты v3:
1. Формат координат `[lng, lat]`: В отличие от Leaflet, API Яндекс Карт принимает массивы строго в формате `[долгота, широта]`. В методах renderMarkers и focusOnStation сделана корректная конвертация.
2. Динамическая ленивая загрузка (Lazy Loading): Скрипт карт загружается методом `loadYandexMapsScript()` только тогда, когда компонент реально монтируется на экран, что экономит трафик и ускоряет первоначальную загрузку приложения.
3. Сохранение чистой архитектуры: Замена Leaflet на Яндекс Карты прошла исключительно на уровне инфраструктурного сервиса. Логика ядра приложения и верстка React-компонента остались нетронутыми.

> В общем, этот кес пока на паузе, т.к. меркантильный Яндекс не предоставил бесплатный ключ для локальной отладки.
