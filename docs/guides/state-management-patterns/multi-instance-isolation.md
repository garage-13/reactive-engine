# Изоляция инстансов и кросс-движковые мосты

В `@pravosleva/reactive-engine` каждый экземпляр класса создаёт собственную независимую среду с изолированным DI-контейнером и планировщиком.

## Области применения
* **Микрофронтенды и плагины:** независимая работа виджетов.
* **SSR (Server-Side Rendering):** разделение контекстов пользовательских запросов.
* **Песочницы и тесты:** изоляция и очистка памяти через `destroy()`.

## Настройка кросс-движковых мостов синхронизации

В примере [здесь](https://pravosleva.pro/p/reactive-engine-communications-between-instances-ru/) движки `hostEngine` и `widgetEngine` (как отдельные инстансы) работают в изоляции, поэтому для передачи данных между ними применяются явные мосты:
* Прямой `.subscribe()` — для фоновой синхронизации сервисов на чистом JS через подписку на изменения сигналов.
* Реактивный `effect` — для автоматического батчинга микрозадач и отслеживания нескольких сигналов одновременно.

## Жизненный цикл динамических виджетов и очистка памяти

При создании временных инстансов движка (например, для модулей аналитики или модальных окон) необходимо вовремя разрывать мосты синхронизации и освобождать память.

### Пример интеграции в React

Для управления жизненным циклом используется хук `useEffect`, который запускает эффект синхронизации при монтировании и вызывает функцию `dispose()` вместе с `widgetEngine.destroy()` при размонтировании компонента. Полный пример реализации доступен в соответствующем разделе документации.

### Сводная таблица выбора способа связи

| Критерий | `.subscribe()` / `engine.effect()` | `useEffect` / `watch` в UI |
| :--- | :--- | :--- |
| **Уровень архитектуры** | Слой данных (`services.ts`) | Слой представления (`Component.tsx`) |
| **Время жизни моста** | Пока живо приложение (или до ручного `dispose()`) | Пока компонент смонтирован на экране |
| **Зависимость от UI** | Отсутствует (работает в чистом JS и Node.js) | Привязано к жизненному циклу фреймворка |
| **Юнит-тестирование** | Тестируется напрямую без рендера DOM | Требует монтирования компонента |
