# Подключение сервисов к UI-фреймворкам (View Layer Integration)

Ключевая архитектурная особенность **`@pravosleva/reactive-engine` v3.0.1** заключается в полном отделении бизнес-логики и графа состояния (`signal`, `computed`, `resource`, `AbstractService`) от конкретного фреймворка рендеринга.

Один и тот же слой сервисов может одновременно обслуживать приложение на **React**, **Vue 3**, **Angular** или **чистом DOM (Vanilla JS)** без переписывания бизнес-правил и тестов.

## Единый принцип интеграции

Независимо от выбранного фреймворка, связывание UI с реактивным ядром строится по трёхшаговой схеме:

1. **Изоляция бизнес-логики в `AbstractService`:** Компоненты не хранят в себе сложную логику запросов, кэширования или валидации — они лишь получают готовый инстанс сервиса через `engine.inject(MyService)`.
2. **Точечная подписка на чтение (Fine-Grained Subscription):** UI-компонент подписывается только на те сигналы и вычисляемые свойства, которые непосредственно отображает в шаблоне (через `useSyncExternalStore` в React, `shallowRef` / адаптер во Vue или `engine.effect` в Vanilla JS).
3. **Декларативный вызов команд:** Пользовательские события (клики, ввод текста, отправка форм) передаются обратно в сервис через вызов его публичных методов (`service.submit()`, `service.toggleTodo(id)`).

## Готовые руководства по фреймворкам

Подробные примеры интеграции, готовые адаптеры и рекомендации по оптимизации рендеринга для конкретных платформ вынесены в отдельные разделы **Быстрого старта**:

* **[Интеграция с Angular 20+](/guides/quick-start/angular)** — преобразование сигналов, вычисляемых свойств и Proxy-объектов в Angular Signals через `toAngularSignal` с автоматической очисткой через `DestroyRef`.
* **[Интеграция с React 18+](/guides/quick-start/react)** — подключение сервисов через `engine.use()` и `useReactiveValue` на базе нативного `useSyncExternalStore` без лишних ререндеров.
* **[Интеграция с Vue 3.2+](/guides/quick-start/vue)** — связывание примитивов ядра с `ShallowRef` через `engine.use()` / `useReactiveValue` с автоматической очисткой в `onScopeDispose`.
* **[Чистый JavaScript и DOM (Vanilla JS)](/guides/quick-start/vanilla)** — прямая привязка эффектов `engine.effect()` и ресурсов к DOM-узлам без виртуального DOM.

## Архитектурные советы при работе с UI

* **Передавайте инстанс `ReactiveEngine` через DI или Context дерева компонентов:** Избегайте жёсткой привязки компонентов к глобальному модульному синглтону, если приложение поддерживает **SSR** или рендерит несколько независимых виджетов на одной странице (подробнее в разделе [Изоляция инстансов и кросс-движковые мосты](./multi-instance-isolation)).
* **Не дублируйте состояние сервиса в локальном стейте компонентов:** Если данные уже живут в `service.items.value` или `service.form`, не копируйте их в `useState` или `ref` без необходимости — держите единый источник истины внутри сервиса.
