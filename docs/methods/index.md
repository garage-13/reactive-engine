    link: /methods/signal
  - title: reactive
    details: Метод `reactive` создает глубоко реактивный объект (Proxy) на основе предоставленного целевого объекта или массива. В отличие от атомарных сигналов (`signal`), которые требуют доступа через `.value`, метод `reactive` позволяет работать с сложными вложенными структурами данных нативно, используя стандартный синтаксис JavaScript для чтения и прямой мутации свойств.
    link: /methods/reactive
