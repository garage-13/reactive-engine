# Пример 253: Long Polling (Vue)

Остановить лонг-поллинг на уровне валидации ответа (`responseValidate`) можно очень изящно. Для этого достаточно прямо внутри этой функции перевести управляющий сигнал `isPollingActive.value` в состояние false.

Поскольку ядро реактивно отслеживает изменения в кортеже зависимостей `apiDeps`, сброс флага активности в false заблокирует прохождение пре-валидации `validateBeforeFetch` для следующего такта.

## Как это работает под капотом:
1. Когда сервер присылает ответ с флагом остановки (например, `status: 'STOP'`), управление переходит в responseValidate.
2. Строка `this.isPollingActive.value = false` переключает состояние сигнала.
3. Это изменение инвалидирует вычисляемое свойство зависимостей `apiDeps`.
4. Движок ядра перед запуском следующего витка опроса вызывает `validateBeforeFetch`. Функция возвращает false, и `withLongPolling` безопасно и окончательно затухает, не отправляя новые запросы в сеть.
