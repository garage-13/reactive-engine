# Пример 050: Сигнал (Angular)

## Архитектурные преимущества для Angular:
1. Интеграция с экосистемой: На выходе метод `.use()` отдаёт честный Angular Signal. Это значит, что вы можете использовать его в Angular-эффектах (`effect(() => ...)`), в вычисляемых сигналах Angular (`computed(() => ...)`), а также задействовать стратегию детекции изменений `ChangeDetectionStrategy`.
2. `OnPush` для максимальной производительности интерфейса.
3. Изоляция: Код ядра и сервисов никак не завязан на специфичный для Angular компилятор Ivy, что позволяет безболезненно поставлять пакет в рамках одной универсальной npm-библиотеки.
