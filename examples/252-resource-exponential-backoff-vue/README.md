# Пример 252: Resource

Пример использует встроенный механизм слотов (`<slot />`) для рендеринга дочерних элементов (аналог `children` в React) и встроенный тег `<Teleport to="body">` для выноса окна на уровень `<body>` (аналог `createPortal`). Стиль, анимации и логика блокировки скролла страницы полностью сохранены по аналогии с Примером 202.

## На что обратить внимание:
1. Модификатор `@click.stop`: Заменяет громоздкую конструкцию `e.stopPropagation()` из React, предотвращая автоматическое закрытие модалки при клике на контентную область.
2. Типизация пропсов (`withDefaults`): Обеспечивает строгие типы TypeScript для параметров компонента и позволяет объявить дефолтные значения прямо в compile-time макросе Vue 3.
